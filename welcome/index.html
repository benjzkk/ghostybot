#welcome

Ghosty can greet new members with fully customizable welcome messages. This section covers everything you need to configure and personalize the welcome system.

#Pages

  • Welcome Message Variables

#Commands

  • /config welcome view — Shows the current configuration of the welcome system.
  • /config welcome message — Sets the welcome message that new members will receive.
  • /config welcome channel — Sets the channel where welcome messages will be sent.
  • /config welcome enable — Enables the welcome system for new members.
  • /config welcome disable — Disables the welcome system for new members.
