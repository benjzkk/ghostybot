    #How to use variables

    Variables allow you to personalize welcome messages with information about the member and the server.

    Configure your message using /config welcome message and include the variables you want to use.

    #Available Variables

    {user}

    Mention of the new member.

    e.g. Welcome @NewMember to the server!

    {username}

    The member's Discord username.

    e.g. Welcome newmember!

    {displayName}

    The member's display name.

    e.g. Welcome New Member!

    {userId}

    The member's Discord user ID.

    e.g. User ID: 123456789012345678

    {server}

    The server's name.

    e.g. Welcome to My Awesome Server!

    {serverId}

    The server's ID.

    e.g. Server ID: 987654321098765432

    {memberCount}

    The current number of server members.

    e.g. We now have 1,247 members!

    {memberNumber}

    The member's assigned join number, if supported.

    e.g. You are member #1,247!

    {owner}

    Mention of the server owner.

    e.g. Contact @ServerOwner for help.

    {date}

    The current date.

    e.g. Joined on January 1, 2026

    {time}

    The current time.

    e.g. Joined at 12:00 PM

    {timestamp}

    A Discord timestamp for displaying a date and time.

    e.g. Joined <t:1735689600:F>

    No variables match your search.

    Note

    Variables must be written exactly as shown. Only variables implemented by Ghosty will be replaced with their corresponding values.
